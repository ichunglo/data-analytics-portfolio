# Data Analytics Portfolio

Projects that turn complex research data into traceable analysis and clear visualizations.

## Projects

### [Drug–Target Landscape](drug-target-landscape/)

**Question:** Which therapeutic targets are linked to the most developed drug records, and where does the available evidence remain incomplete?

An end-to-end research analysis using **SQLite, SQL, Python, and Matplotlib**. It combines source reconciliation, data-quality checks, reproducible visualizations, and an [interactive dashboard](https://ichunglo.github.io/posts/2026-10-02-drug-target-landscape/).

**Explore:** [Project overview](drug-target-landscape/) · [Results and figures](drug-target-landscape/docs/RESULTS.md) · [Methods](drug-target-landscape/docs/METHODS.md) · [Analytics dashboard](https://ichunglo.github.io/data-analytics-portfolio/drug-target-landscape/dashboard/) · [Full blog explorer](https://ichunglo.github.io/posts/2026-10-02-drug-target-landscape/)

The results describe the included records—not a complete clinical-trial cohort or a clinical success rate.
